# Taste Duel documentation

[Play Taste Duel](https://tasteduel-web-902056825143.asia-south1.run.app) or start with [Playing](playing.md).

Taste Duel turns Qloo’s request-specific cultural ranking into a five-round prediction game. Qloo supplies the evidence, a bounded Vertex curator constructs the journey, and deterministic services control the answers. Prediction correctness is game performance; only the selected favourite and explicitly saved discoveries are user-selected signals.
