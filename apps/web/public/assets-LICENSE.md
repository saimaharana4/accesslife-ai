# Taste Duel prototype artwork

The SVG files in `public/art/` are original geometric illustrations created for
Taste Duel on 24 October 2026. They use no external photographs, film posters,
album covers, logos, fonts or embedded third-party material. Fictional titles
are presented separately in the application, not claimed to be real works.

- `afterlight.svg`: orbital target and diagonal print forms.
- `velvet-static.svg`: record-inspired rings, optical chevrons and waveform.
- `blue-hour.svg`: nested triangles, horizon grid and geometric stars.
- `slow-burn.svg`: abstract flame silhouette and print-registration forms.

These project-created SVG/CSS assets are covered by the repository MIT licence.
They are synthetic prototype presentation assets, not Qloo data or evidence of
Qloo image reuse permission. No external API is required to display them.

Locally hosted typefaces have their own OFL notices in `public/fonts/`; those
notices govern the font files. The root project licence does not replace them.

## Challenge social cards (26 October 2026)

The dynamically rendered challenge card uses original typography, a dashed ticket
seam and project-created SVG asterisk geometry. Only an authorized invitation's
seed title and actual creator score are displayed; no external artwork is fetched.
Barlow Condensed uses its existing local OFL font. The raster card transliterates
Latin accents and replaces unsupported glyphs with `?` to prevent next/og from
downloading fallback fonts or emoji; the invitation and metadata preserve the full
original title. Long raster titles are bounded to 140 characters.
